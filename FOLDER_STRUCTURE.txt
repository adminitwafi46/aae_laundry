ARCHITECTURE FLOW:
===================

1. REQUEST FLOW:
   HTTP Request
      ↓
   routes/api.php OR modules/[Module]/Routes/api.php
      ↓
   modules/[Module]/Http/Controllers/[Controller].php
      ↓
   modules/[Module]/Services/[Service].php
      ↓
   modules/[Module]/Repositories/[Repository].php
      ↓
   modules/[Module]/Models/[Model].php
      ↓
   Database
      ↓
   JSON Response (via ApiResponseTrait)

2. MODULE LOADING FLOW:
   Application Boot
      ↓
   app/Providers/ModuleServiceProvider.php
      ↓
   Reads config/modules.php
      ↓
   Auto-registers each module's ServiceProvider
      ↓
   Each module loads its own routes and migrations
